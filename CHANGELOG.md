# Changelog

## 0.3.17

Initial public source package. Users configure their own TeraTTS-compatible
server; new profiles no longer use a maintainer-owned default address. Valid
existing endpoint values are retained. The package includes native panel
previews, a silent inert demonstration, setup/removal guidance and public-content
checks. The private development history and machine journals are not included.

The preceding panel includes Read / Files / Settings, semantic icons beside
labels, selected larger A, measured playback bands, a fixed footer, saved-file
preview/export controls and native clip-edge clearance. Existing OCR adapters,
configuration/keyring storage and cancellation paths remain.
